# わかりやすいやりたいこと
- レーンは6個。
- 基本的にレーンはアルファベット、数字、記号(例 , . / など)のキーはすべて反応する。
- 赤のノーツ、またはレーンが赤の場合はキーはs,d,fのどれかで反応する。
- 青のノーツ、またはレーンが青の場合はキーはj,k,lのどれかで反応する。
- レーンが黄色だったら左からそれぞれs,d,f,j,k,lと対応するレーンが一つずつある。
